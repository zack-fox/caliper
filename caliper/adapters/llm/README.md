# adapters/llm · 预留目录（当前为空实现）

首版明确不接大模型：仓库内不得出现 `openai` / `anthropic` / `requests` / `httpx` 等依赖，
`make lint` 会扫描并报错。

未来接入时的边界：

1. **只做草稿**：输出映射到 `core.ports.AnalysisDraft`，字段为空就保持为空，不得编造证据与结论。
2. **人工确认**：草稿必须经人工确认后才可进入四张表；端口调用失败不得阻断导出。
3. **离线优先**：现场默认无外网；接入必须是显式开启的可选项。
4. **不入判定**：模型输出永远不改变 `judge` 的五值结论，只影响人工分析列。
5. **不碰敏感数据**：发送前必须脱敏（系统名、IP、账户、项目编号一律替换为占位）。
6. **制度类扩展**：后续「安全管理制度」测评走同一端口，但需要独立的 pack 与证据来源。

实现方式：新建 `adapters/llm/analyzer.py` 实现 `AnalyzerPort`，在 `app` 或 CLI 中显式装配，
默认仍装配 `adapters.noop.NoopAnalyzer`。
