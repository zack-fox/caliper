# 网络安全设备人工核查模板

以下设备类型尚无厂商指导书，先建立人工核查模板：
不提供采集命令，所有测评项按人工核查处理；取得厂商资料后再补充专用采集适配器。

| 适配器 | 设备类型 | 可识别的资产厂商/类型 | 等级 |
| --- | --- | --- | --- |
| firewall | 防火墙 | 防火墙、firewall、fw、ngfw、下一代防火墙 | 2,3,4 |
| waf | WAF | WAF、web应用防火墙、web 应用防火墙 | 2,3,4 |
| ids_ips | IDS/IPS | IDS/IPS、ids、ips、idps、入侵检测、入侵防御 | 2,3,4 |
| vpn | VPN | VPN、ssl vpn、ipsec vpn、虚拟专用网 | 2,3,4 |
| bastion | 堡垒机 | 堡垒机、bastion、运维审计、跳板机、jump server | 2,3,4 |
| load_balancer | 负载均衡 | 负载均衡、load balancer、lb、adc | 2,3,4 |
| gap | 网闸 | 网闸、隔离网闸、安全隔离与信息交换、gap | 2,3,4 |
